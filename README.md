## 👋 About me

I'm a full-stack developer who likes owning the whole picture: designing the database, wiring up authentication, building the API and shipping the screens people actually use — on the web and on mobile.

- 🎮 **Building** a second-hand game trading & selling marketplace
- 💳 **Building** a QR-based pay-at-the-table app for cafés and restaurants
- 📈 **Tinkering** with an algorithmic trading bot (backtesting + risk management)
- ✍️ **Writing** about what I learn on [Medium](https://medium.com/@aftekardic)
